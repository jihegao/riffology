# Model visualization contract

The generated document is a local, standalone HTML review artifact. It must:

1. identify the source path, generated time, and SHA-256 digest;
2. preserve model-spec terminology without translating assumptions into facts;
3. show unavailable sections explicitly;
4. be self-contained (no CDN, server, iframe, or runtime API dependency);
5. be opened through the operating system's default external browser after it is written.

The source specification/code remains authoritative. A diagram neither validates the model nor proves a simulation outcome.
