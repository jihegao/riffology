# Wind Turbine Maintenance Visual Simulator

This reviewed local companion runs the synthetic Mesa wind-turbine maintenance
model as a `riff-visual-v1` child. It exposes a health endpoint, a bounded
structured inspection endpoint, and an interactive browser page for stepping,
playing, resetting, and inspecting one frozen visual sample.

The page is an inspection surface, not evidence of calibration, numerical
equivalence to another runtime, or a staffing recommendation.
